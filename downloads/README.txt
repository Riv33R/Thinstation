В эту папку помещаются проприетарные RPM-дистрибутивы, которые ThinStation не может скачивать автоматически из-за лицензионных ограничений вендора.

Для клиента Omnissa / VMware Horizon положите сюда файл:
Omnissa-Horizon-Client-2506-8.16.0-16536624989.x64.rpm

(или переименуйте ваш RPM-пакет клиента Horizon в это имя, либо укажите нужное имя в build.conf через param horizonurl).
